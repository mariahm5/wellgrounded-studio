# Well Grounded, with Mariah Marcum

This is Mariah's website, https://wellgrounded.studio. Everything on the site lives in this folder. Any change saved here goes live in about a minute.

## Changing the site with AI (no coding needed)

Use whichever AI you already pay for. Each one can open this project on GitHub, make the change, and hand it back for you to approve.

| You use | Open | Connect |
|---|---|---|
| ChatGPT | chatgpt.com/codex | Connect GitHub, then pick **wellgrounded-studio** |
| Claude | claude.ai/code | Connect GitHub, then pick **wellgrounded-studio** |
| Gemini | jules.google | Connect GitHub, then pick **wellgrounded-studio** |

Then:

1. **Say what you want in plain words.** For example:
   - "Change my about text to say I've been teaching since 2020."
   - "Add this photo to the About section" (attach it).
   - "Add a new quote from a student named Jess: …"
   - "Make the Classes section mention my new Sunday class."
2. **Look at the preview or summary it gives you.** If it's right, press **Merge** (or **Create PR**, then **Merge** on GitHub). It's live a minute later.
3. **If something looks wrong,** ask the same AI: "Undo the last change." Every old version is saved.

The AI reads `AGENTS.md` first. That file holds your brand rules (colours, fonts, no italics, how photos should look) and the things to protect (GoYoga's name, student privacy, careful pregnancy wording). If you change your mind about a rule, just tell the AI and ask it to update `AGENTS.md` too.

## Small text fixes on GitHub itself

1. Open `index.html` on github.com.
2. Click the pencil icon.
3. Find the words (Cmd+F), change them, and click **Commit changes**.
